# JARVIS v1

Assistente de voz com IA (Gemini) que roda direto no navegador, com interface estilo HUD.

**Abrir:** https://boymotos0123-web.github.io/jarvis-v1/

## O que ele faz
- Conversa por voz (diga "JARVIS" para ativar) e responde com voz
- Lembra das conversas e do que aprende sobre você
- "Abre a câmera", "mostra as notícias", "passa o canal", "faz um resumo"
- Pode ser interrompido: diga "JARVIS", "chega" ou "pare"

## Como usar
1. Abra o link no Google Chrome
2. Cole sua chave da API do Gemini na primeira tela (ela fica salva só no seu navegador)
3. Libere o microfone e diga "JARVIS"

A chave **não** fica no código: cada pessoa usa a sua.
